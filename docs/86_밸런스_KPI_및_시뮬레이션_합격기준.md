# 86. 밸런스 KPI 및 시뮬레이션 합격기준

> 목적: “코드는 정상이나 성장·경제·던전·NPC 생태가 망가진 상태”를 자동/반자동으로 검출한다. 원문 확정 수치와 아래 「설계 보완안 초기 목표범위」를 분리한다.

## 1. 검증 Seed Pack

| Pack | Seed 수 | 목적 |
|---|---:|---|
| SMOKE | 10 | 즉시 회귀/불변식 |
| STANDARD | 100 | 기능 분포 |
| BALANCE | 1,000 | 일반 밸런스 비교 |
| STRESS | 10,000+ | 꼬리분포/장기 안정성 |
| RARE | 100,000~1,000,000 | 1% 이하 강화/각인 등 희귀확률 검증 |

## 2. KPI 공통 판정

- 평균만 보지 않고 P10/P25/P50/P75/P90/P95/P99와 실패 꼬리를 함께 본다.
- Golden Seed는 결과 자체뿐 아니라 AI 분기/이벤트 trace 차이를 비교한다.
- 통계적 차이가 발생해도 설계 변경에 의해 의도된 것인지 Review Decision 없이 자동 승인하지 않는다.
- 같은 balanceVersion 내에서 동일 fixture의 기대 분포가 임의로 변하면 Regression으로 본다.

## 3. 전투 KPI

| KPI | 원문 기준 | 초기 합격기준 보완안 |
|---|---|---|
| 전투 결정론 | 동일 seed/입력 동일 결과 | stateHash 100% 일치 |
| 일반 6v6 이벤트량 | 평균 40초 기준 약 500~2,000 event 목표 | P95가 설계 상한을 지속 초과하면 FAIL |
| 적정 위험 던전 성공률 | 숫자 확정 없음 | STANDARD에서 55~80% 구간을 초기 목표로 사용, 난이도 라벨별 별도 Calibration |
| 후퇴 가치 | 핵심 전략 | 무조건 끝까지 싸우기가 최적이 되지 않도록 위험 구간에서 후퇴 선택의 기대손실 감소 확인 |
| 역할 다양성 | 준비/구성 중요 | 단일 조합이 모든 일반 콘텐츠에서 우월하면 Review |
| 상태이상 | 종족 면역/저항 존재 | 면역 무시/중첩 무한/영구 CC 0건 |

## 4. 성장 KPI

| KPI | 기준 |
|---|---|
| 레벨 성장 | 초반 빠름, 중반 점진 둔화, 100 전후 강한 soft-cap |
| 전투력 구성 | 레벨/스탯 약30%, 장비30~35%, 스킬20~25%, 파티/전술15~20% 권장 |
| 스탯 투자 | 10~30 비용1, 31~45 비용2, 46~60 비용3, 61~75 비용5, 76+ 일반 자유포인트 금지 |
| 클래스 고정 | 클래스 승급/클래스 레벨 없음; 성장축과 혼동 금지 |
| 세대 계승 | 레벨/개인관계 복사 금지, 가문 자산·유물·귀환기록·세계상태 유지 |

## 5. 강화 KPI

원문 성공률은 +1~5 100%, +6 90%, +7 80%, +8 70%, +9 60%, +10 50%, +11 40%, +12 32%, +13 25%, +14 18%, +15 12%, +16 8%, +17 5%, +18 3%, +19 2%, +20 1%를 기준으로 한다.

| KPI | 합격기준 |
|---|---|
| 확률 적합도 | RARE pack에서 각 구간 관측률이 이항 신뢰구간/사전 승인 tolerance 밖이면 FAIL |
| 실패 집중도 | 구간별 최대 누적을 넘지 않음, 성공 시 해당 단계 집중도 초기화 |
| 파괴 여부 | 표준 규칙에서 강화 실패 장비 완전 파괴 0건 |
| 보호석 | 실패 시 하락만 방지하고 재료/집중도 규칙은 정상 적용 |
| 기본 성장 | 성공 시 핵심 기본 성능 반드시 증가 |
| 강화 각인 | 장비당 기본 1, 활성 슬롯 최대3; 확률 상한 1% |
| 저장 재시도 | 동일 장비/attemptNo/seed는 동일 결과 |

## 6. 던전 생태 KPI

| KPI | 원문 기준 | 초기 판정 |
|---|---|---|
| 신규 던전 | 하루 25~50, 평균 약35 권장 | 360일 STANDARD에서 평균/등급분포 비교 |
| 등급 분포 | F30/E25/D20/C13/B7/A3.5/S1.3/SS0.2%, EX 자연발생 없음 | χ²/구간 tolerance로 검증 |
| 규모/등급 독립 | A 소형/F 대형 가능 | 금지 조합 외 상호 독립 분포 확인 |
| 탐색/정복 분리 | 100% 탐색 불필요 | 정복100/탐색<100 fixture PASS |
| 브레이크 | 방치 시 성장/불안정/브레이크 | 무한 안정/즉시 브레이크 편향 탐지 |

## 7. 경제 KPI

| KPI | 초기 합격기준 보완안 |
|---|---|
| Gold Source/Sink | 30/90/360일 단위 source와 sink 비율을 기록; 한쪽이 장기 2배 이상 우세하면 Review |
| 가격 안정 | 평시 품목지수가 상·하한 없이 단조 폭증/0 수렴하지 않음 |
| 던전 자원 충격 | 브레이크/광물 던전 등 원인 이벤트 후 관련 품목 방향성이 설계와 일치 |
| 거래 원자성 | 구매/판매/경매/대여 정산 중복·음수잔액 0건 |
| 강화 경제 | +15/+20 기대 비용 분포를 장기 Gold 생산량과 비교해 최종장비가 trivial하지 않은지 확인 |

## 8. NPC/인구 KPI

| KPI | 원문 기준/합격 |
|---|---|
| 현역 용병 | 평시 1,500~2,200, 중심 약1,900 |
| 인구 순환 | 초기 1,900명이 100년 내내 그대로 유지되는 상태 금지 |
| 장기 유입/은퇴 | 신규등록·휴업·복귀·직업전환·이주가 실제 분포에 존재 |
| 상세/축약 동치 | S3/S4 압축 전후 핵심 자산/관계/진행 결과가 허용 오차 내 동등 |
| 동일 seed 정체성 | 이름/초상/잠재력 등 생성 계약이 version 범위에서 재현됨 |

## 9. 랭킹 KPI

- 길드/파티 공식 총점은 0~10,000 범위 밖으로 나가지 않는다.
- 길드원 수 단순합만으로 상위가 되지 않도록 핵심 전력/공략/정보/재정/평판/안정 요소의 민감도를 확인한다.
- 동일 저등급 던전 반복의 효율 감소가 실제 랭킹 시뮬레이션에서 나타난다.
- 30일 연속 1위 조건은 일별 마감 snapshot을 기준으로 끊김 없이 계산한다.

## 10. 장기 캠페인 KPI

| 기간 | 검증 |
|---|---|
| 1년 | 기본 경제/던전/NPC 활동이 정지하지 않음 |
| 10년 | 길드·파티·NPC 세대 변화와 사건 다양성 |
| 100년 | 인구 안정성, 연대기 압축, 세대 승계, 경제 폭주 여부 |
| 300년 | 데이터 성장·메모리·상태머신 dead-end·귀환 조건 도달 가능성 |

## 11. PASS/FAIL 운영

```text
PASS: 불변식 100% + Golden regression 승인 + KPI 허용범위
REVIEW: 기능은 정상이나 분포가 baseline 경계 초과
FAIL: 정합성/결정론/범위 위반 또는 의도하지 않은 경제·인구 폭주
```

모든 FAIL seed는 재현 패키지에 engine/content/balance/schema/rng version, seed, command sequence, state hash, 핵심 trace를 포함한다.

## 12. KPI별 통계 판정 방법

| 유형 | 판정 방법 | 예 |
|---|---|---|
| 확률형 | 기대확률과 관측확률의 신뢰구간/승인 tolerance 비교 | 강화 성공, 접사, 던전 등급 |
| 분포형 | P10~P99와 baseline quantile 비교 | TTK, Gold, 부상, 탐험시간 |
| 범위 불변식 | 모든 seed에서 범위 위반 0건 | 랭킹 0~10,000, 음수 Gold 금지 |
| 장기 안정성 | 1/10/100/300년 시계열 추세/변곡점 | 인구, 시장, 길드 집중 |
| 선택 다양성 | 상위 전략 점유율/압도적 Dominant strategy 탐지 | 클래스/파티/장비/전술 |
| 동치성 | 동일 입력의 stateHash 또는 허용 Projection 오차 | 상세↔축약 NPC, 최적화 전후 |

희귀 확률은 작은 표본의 단순 퍼센트 차이로 실패시키지 않는다. 예를 들어 +20 1% 성공률은 RARE pack에서 충분한 표본을 확보하고, Seed/attempt 독립성과 pity/stability 보정을 분리하여 분석한다.

## 13. 밸런스 Baseline Artifact

각 승인 baseline은 최소 다음을 저장한다.

```text
balanceVersion
engineVersion
contentVersion
schemaVersion
rngVersion
scenarioId
seedStart/seedCount
metricDefinitionVersion
quantiles
mean/stddev
failCount
outlierSeeds[]
artifactHash
reviewDecisionId
```

평균/분포가 바뀐 경우 새 baseline을 덮어쓰지 않고 이전 version과 비교 가능하게 보존한다.

## 14. 밸런스 이상 징후 자동 경보

| 경보 | 조건 예 | 조치 |
|---|---|---|
| `RUNAWAY_ECONOMY` | Gold/가격지수가 장기 단조 폭증 | source/sink 및 시장지수 trace |
| `POPULATION_COLLAPSE` | 현역이 장기 정상범위 아래에서 복구하지 못함 | 유입/은퇴/이주 원인 분해 |
| `POPULATION_EXPLOSION` | 상한을 지속 초과 | 신규등록/세대 코호트 정책 검토 |
| `DUNGEON_BACKLOG` | 생성량이 정복량을 장기 압도 | 발생/공략/브레이크 균형 검토 |
| `DOMINANT_BUILD` | 특정 조합이 대부분 난이도에서 압도 | 상성/자원/전술 민감도 검토 |
| `DEAD_CONTENT` | 특정 클래스/스킬/아이템 사용률이 사실상 0 | 획득성/효율/요구조건 확인 |
| `RANKING_LOCK` | 상위 길드가 장기 교체 불가능 | 점수 구성/인재·재정 snowball 확인 |
| `SUCCESSION_DEAD_END` | 적격 후계자 없이 캠페인 진행불가 | 안전장치/입양/지정 후보 검토 |
| `RETURN_UNREACHABLE` | 장기 seed에서 귀환조건 이론상/실질상 도달 불가 | 증표/잔존던전/90일 종전 조건 검토 |

## 16. 밸런스 Definition of Done

- [ ] 불변식 위반 0건이다.
- [ ] Golden Seed 변경은 승인된 설계 변경으로 설명된다.
- [ ] 각 KPI에 metric 정의와 sample size가 있다.
- [ ] 평균뿐 아니라 꼬리분포와 이상 seed를 검토했다.
- [ ] 100년 및 300년 장기 시뮬레이션에서 경제/인구/길드/던전이 dead-end에 빠지지 않는다.
- [ ] 신규 balanceVersion에는 이전 baseline과의 Diff 및 승인 기록이 있다.
