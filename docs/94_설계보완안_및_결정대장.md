# 94. 설계 보완안 및 결정대장

> v31.4 · 확정 원문과 제안 구분. 2026-09-09 사용자의 최적안 일괄 결정 승인으로 C01~C22 설계 선택안을 모두 기준선에 반영했고, 2026-09-10 C23으로 Phase 0 원자 Assertion 범위·소유 분류를 확정했다. C24는 2026-09-13 Phase 1 개발리더 설계 검토에서 원문 예시와 확정 보안·호환·Phase 소유권을 정합화한 기술 기준선이다. 실제 저장소·실물 자산·실기기 측정 증거는 별도 Gate이며 승인된 설계 결정을 미결정으로 되돌리지 않는다.

## 1. 근거 우선순위
현재 첨부 문서의 명시적 최종/대체 조항, 동일 범위의 상세 조항, 개요/초기 예시 순으로 해석한다. 번호가 크다는 이유만으로 자동 덮어쓰지 않는다. 모순의 범위가 명확하지 않으면 양쪽을 보존하고 결정 대기로 둔다. 이전 대화나 사용자 메모를 첨부 자료에 없는 범위를 추가하거나 최신 첨부 규칙을 변경하는 근거로 사용하지 않는다.
