### 실물 자산 승인 계약

자산은 ID 행이나 파일명만으로 완료 처리하지 않는다. 배치마다 `AssetManifest`에 논리 ID, 상대 경로, SHA-256, MIME, 픽셀 크기, byte 크기, alpha/색공간, 출처·라이선스·배포 허용 범위를 기록한다. 검수는 파일 존재·중복 SHA-256 0건·decode 성공·요청 크기 decode·저해상도/손상 fallback·누락 시 접근 가능한 placeholder·asset-pack 용량을 확인한다. 지각 hash 근접 후보는 자동 탈락시키지 않고 목록화해 사람 검수한다. 출처나 배포권 증거가 없거나 실제 파일이 없으면 `BLOCKED_ASSET`이며 출시 Gate에서 수량으로 상쇄하지 않는다.

C18의 설계 결정은 완료했다. 고정 풀은 `NPC-M-00001..05000`과 `NPC-W-00001..05000`을 `.png` 또는 `.webp` 중 하나의 동일 확장자로 제공하며, 200×200 px, opaque sRGB로 고정하고 install-time `portraits_v1` pack으로 배포한다. pack 압축 크기 512 MiB 이하, 전체 install-time 압축 크기 768 MiB 이하가 합격 기준이다. 런타임 생성, fast-follow, on-demand로 10,000장 실물 검수를 대체하지 않는다. 실제 파일과 검사 결과가 없는 현재 P23/P25 실행 상태는 `NOT_RUN/BLOCKED_ASSET`이지만 C18 자체는 미결정이 아니다.
