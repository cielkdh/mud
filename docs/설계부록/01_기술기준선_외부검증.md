# 기술 기준선 외부 확인

> 확인일 2026-09-08. 원문게임규칙이아닌기술 API/공식발표의외부확인이다. 실제이프로젝트에서의 resolve/컴파일/성능검증은수행하지않았다.

## E01. Room3
Android 공식릴리즈문서의 stable 은3.0.2(2026-08-26)이다. 새그룹/패키지는`androidx.room3`,runtime/compiler 와 Gradle plugin 도 room3 계열이다. KSP/Kotlin 생성/코루틴 API/SQLiteDriver,FTS5 지원을기준으로삼는다. transaction 예시는`withWriteTransaction`이며 Room2 의 API 를그대로복사하지않는다. schemaDirectory 와 N→N+1migration 을테스트계약에포함한다.
```text
https://developer.android.com/jetpack/androidx/releases/room3
```

## E02. AGP 기준
AGP9.4.0 공식문서는 Gradle9.6.0/JDK17/API37 지원범위를안내한다. 이는원문시작후보의검토근거이고 Kotlin/KSP/Compose/Coil 등전체조합컴파일성공을뜻하지않는다. 정확 patch 는 P0 version catalog 에서잠근뒤실제빌드한다.
```text
https://developer.android.com/build/releases/agp-9-4-0-release-notes
```

## E03. SQLite 격리
SQLite 공식설명에따라쓰기직렬화와 WAL snapshot 읽기를고려한다. 이게임의단일작성자/불변 plan 은프로젝트설계 결정이다. SQLite 가도메인불변식/멱등성을자동보장한다고가정하지않는다.
```text
https://sqlite.org/isolation.html
```

## E04. 안전한 DB 백업
SQLite 공식 backup API 문서를근거로실행중 DB 의 main 파일단순복사를피한다. 실제 Android 드라이버에서사용가능한 online backup 또는검증된 close/checkpoint barrier 를선정하는것은 P3 spike 대상이다.
```text
https://sqlite.org/backup.html
```

## 확인하지 않은 항목
원문의 Kotlin2.4/ComposeBOM2026.08/Coil3.6/DataStore1.2/WorkManager2.11 등정확한전체조합은이문서에서독립 compile 하지않았다. 현재 GooglePlay 배포정책도출시당일다시확인해야한다. source 의 targetSdk 일정표를미래영구정책으로확정하지않는다.
